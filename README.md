# Mind Melody

A personal, interactive portfolio for Syan (Isyana Arlisya), exploring psychology, music, emotions, and research through a warm editorial visual style.

## Tech stack

- Next.js App Router and React
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons

## Features

- Animated intro and responsive illustrated hero
- Five-part personal story with editorial section markers
- Explore menu with interactive mood music, research questions, personal interests, and projects
- Original short piano motifs generated in-browser with the Web Audio API; audio only plays after a visitor selects a mood
- Accessible navigation, reduced-motion support, and responsive layouts

## Run locally

Use Node.js 20.9 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` in your browser.

## Deploy to Vercel

Import this repository into Vercel and keep the project root at the repository root. Vercel detects Next.js automatically; its standard build command is `pnpm build`.
